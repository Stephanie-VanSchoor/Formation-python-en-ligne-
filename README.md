# 🐍 Formation Python Pro

Plateforme de formation en ligne avec 54 leçons Python, de débutant à expert.

## 🚀 Fonctionnalités
- 5 modules / 54 leçons
- Quiz interactifs
- Suivi de progression
- Certificat
- Forum d'entraide
- Paiements Stripe

## 🛠️ Installation

bash
git clone https://github.com/votre-nom/formation-python-pro.git
cd formation-python-pro
python -m venv venv
source venv/bin/activate  # ou venv\Scripts\activate sur Windows
pip install -r requirements.txt
python app.py
